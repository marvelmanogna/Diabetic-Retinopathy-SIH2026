About DR Screening AI (SIH 2026)

RETINA-AI: Explainable Diabetic Retinopathy Screening System

Built for the Smart India Hackathon (SIH 2026), this deep learning diagnostic workstation empowers non-specialist clinicians with automated fundus screening.

  • Deep Learning Backbone: Fine-tuned Deep CNN (ResNet-18) trained on the APTOS 2019 Blindness Detection dataset.
  • Explainability Layer: Gradient-weighted Class Activation Mapping (Grad-CAM) illuminating decision regions for clinical trust.
  • Biomarker Segmentation: Morphological vessel tree segmentation and bright lesion / exudate candidate localization.
